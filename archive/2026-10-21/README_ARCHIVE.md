# Archived submitted workflow

This folder preserves the analysis code, utilities, README, launchers, and configuration template present immediately before the new CCX run was built on October 21, 2026. Uncommitted edits were preserved. The private site configuration was not copied.

The archive documents the submitted analysis, including methods criticized in review. It is not the workflow for the revision. Its scripts expect their original repository layout and historical inputs; preservation does not imply they can run in place here.

Historical site returns remain under the repository's `sites/` directory, and figures and pooled outputs remain in place. The new pipeline never discovers those directories automatically.
